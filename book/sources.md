## Textbook and assignment differences

- **Fun versus ML− equality:** the English book p.152 includes list equality and leaves nested details open. HW2 p.3 explicitly excludes list equality. See the [HW2 comparison](hw2.html#what-transfers-from-textbook-fun).
- **Factorial:** the draft loop on p.78 starts multiplication at zero. The [Chapter 2 note](textbook-02.html#check-the-draft-s-factorial-boundaries) identifies the error and supplies a zero-safe recursive example.
- **State interfaces:** the textbook download shares an engine across Chapters 6–7; its `SET` and evaluator mode differ from B's `ASSIGN` and public starter. See [HW3 adaptations](hw3.html#what-transfers-from-chapters-6-and-7).
- **Checker results:** the textbook demo can enumerate scalar equality types, whereas HW4 returns one type. See [the declared HW4 policy](hw4.html#what-transfers-from-chapter-8).
- **Object creation:** Lecture 11 p.24's formal freshness premise uses the store after argument evaluation, while its numbered prose lists allocation first. The [object guide](10-objects.html#object-creation-has-a-sequence) gives an implementation order that satisfies the premise and does not assume default field values.

## Source discrepancies to keep in mind

- **Unavailable links:** `slides/fixpoint.pdf`, `howtotryml.pdf`, and the additional linked `code/let.ml` returned HTTP 404 at the recorded snapshot. No substitute is presented as an original 2026 file. Fixed points remain covered in HW2 pp. 7–9 and lecture 20; the official GitHub repository provides local setup instructions.
- **Lecture 11:** the course page links it both under classes and under static types. The PDF is titled “Classes and Objects”; static typing starts in lecture 12.
- **Lecture 8 numbering:** it has 39 PDF pages; some slide footers retain an older total. All companion links use the PDF page index.
- **HW2, p. 3:** the mutual-recursion call rule is visibly missing the result after its final evaluation arrow. Read its intended result as the value from the body premise. The print rule is schematic; the surrounding prose requires evaluating and printing the operand.
- **HW2, p. 6:** example 3’s prose calls even on 13, while the supplied AST calls odd on 13 and the expected result is true. Trace the AST: odd(13) is true; even(13) is false.
- **HW3, p. 1:** prose mentions read, but the provided AST contains no READ constructor. Its implementation contract is the actual listed AST.
- **HW4, pp. 1–2:** it refers to ML− from HW3; in this course listing ML− is HW2, while HW3 is B. The type-checker AST matches HW2. Its brief handout leaves several typing-policy details unstated; see the [HW4 guide](hw4.html).
- **Lecture 18, p. 13:** the procedure typing rule contains an inconsistent parameter-type symbol. The explanation uses the ordinary monomorphic parameter rule, distinguished from let generalization.

These observations concern the downloaded snapshot and are companion notes, not instructor-issued errata. The download script can be rerun to check for later source changes.
