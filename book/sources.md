## Source discrepancies to keep in mind

- **Unavailable links:** `slides/fixpoint.pdf`, `howtotryml.pdf`, and the additional linked `code/let.ml` return HTTP 404. No substitute is presented as an original 2026 file. Fixed points remain covered in HW2 pp. 7–9 and lecture 20; the official GitHub repository provides local setup instructions.
- **Lecture 11:** the course page links it both under classes and under static types. The PDF is titled “Classes and Objects”; static typing starts in lecture 12.
- **Lecture 8 numbering:** it has 39 PDF pages; some slide footers retain an older total. All companion links use the PDF page index.
- **HW2, p. 3:** the mutual-recursion call rule is visibly missing the result after its final evaluation arrow. Read its intended result as the value from the body premise. The print rule is schematic; the surrounding prose requires evaluating and printing the operand.
- **HW2, p. 6:** example 3’s prose calls even on 13, while the supplied AST calls odd on 13 and the expected result is true. Trace the AST: odd(13) is true; even(13) is false.
- **HW3, p. 1:** prose mentions read, but the provided AST contains no READ constructor. Its implementation contract is the actual listed AST.
- **HW4, pp. 1–2:** it refers to ML− from HW3; in this course listing ML− is HW2, while HW3 is B. The type-checker AST matches HW2. Its brief handout leaves several typing-policy details unstated; see the [HW4 guide](hw4.html).
- **Lecture 18, p. 13:** the procedure typing rule contains an inconsistent parameter-type symbol. The explanation uses the ordinary monomorphic parameter rule, distinguished from let generalization.

These observations concern the downloaded snapshot and are companion notes, not instructor-issued errata. The download script can be rerun to check for later source changes.
